# Exam Platform — Django REST Framework & React

A web-based exam platform built with Django REST Framework and React. The project supports school management, classrooms, teachers, students, and online exams.

### Features
- Role-based access for school admins, teachers, and students.
- School and classroom management.
- Exam creation with multiple-choice questions and configurable durations.
- Student exam attempts, answer submission, and score calculation.
- Student profiles and exam history.
- React frontend connected to the Django REST API.

### Tech Stack
- **Backend:** Python, Django, Django REST Framework
- **Frontend:** React, TypeScript, Vite
- **Database:** PostgreSQL

### Project Status
This project was built primarily for practice and learning, with a focus on backend development, API design, permissions, and frontend integration. The frontend was developed with the assistance of AI.

The project has not yet reached production-ready standards. Before using it as a real product, the frontend and backend need further review, particularly the permission system, access control, and frontend security. Testing, error handling, and overall reliability should also be evaluated and improved.

At a higher level, caching should be designed and implemented where appropriate to improve performance as the application grows.

This is a learning project and a foundation for further development, not a production-ready exam platform.
